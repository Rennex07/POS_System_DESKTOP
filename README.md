# POS System

A local Point of Sale (POS) desktop application built with Python, specifically designed for restaurants. This system provides a complete solution for managing orders, inventory, transactions, and business analytics with a modern, intuitive interface.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![PySide6](https://img.shields.io/badge/PySide6-Qt6-green)
![License](https://img.shields.io/badge/License-GPLv3-blue)

## Features

### Ordering Menu
- Visual menu with item images and categories
- Quick order processing with customizable quantities
- Real-time cart management
- Support for custom item options (sugar levels, etc.)
- Automatic receipt generation

### Inventory Management
- Add, edit, and delete menu items
- Track stock levels with low-stock alerts
- Category-based organization (Appetizers, Mains, Desserts, Drinks, Casual)
- Image support for menu items
- Bulk inventory operations

### Transaction History
- Complete transaction records with timestamps
- Detailed item breakdown per transaction
- Search and filter transactions
- View transaction details in popup dialogs
- Export transaction data to CSV/JSON

### Analytics Dashboard
- Real-time sales statistics
- Revenue tracking and visualization
- Top-selling items analysis
- Monthly and daily sales reports
- Custom bar charts for data visualization
- Export reports to PDF/CSV

### Export Capabilities
- Export inventory to CSV or JSON
- Export transactions to CSV
- Generate PDF receipts
- Create monthly sales reports (HTML/PDF)
- Low stock reports with restocking recommendations

### Clean UI/UX
- Clean light theme design
- Smooth animations and transitions
- Responsive layout
- Intuitive navigation sidebar
- Real-time status updates
